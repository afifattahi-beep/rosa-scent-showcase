# Rosa Scent Showcase

Build a complete, responsive website for a luxury perfume brand called **Rosa Fragrance**. Deliver it as a single self-contained HTML file with inline CSS and JavaScript, using no frameworks or external dependencies except Google Fonts.

## Brand & design

- Mood: luxury, elegant, romantic and refined, like a high-end fragrance house. The brand name comes from the rose, so add subtle rose-inspired touches (soft petal gradients, delicate line ornaments) without overdoing it.
- Base colors: warm ivory background, deep burgundy and rose gold accents, near-black text.
- Typography: Cormorant Garamond for headings, Montserrat for body text.
- Generous white space, smooth scrolling, gentle fade-in and hover animations. No clutter.
- Tagline: **"The Essence of Elegance"**

## Products

All are oil-based perfumes in 6 ml bottles, priced at **৳190 each**. Each product's card, bottle illustration and accent color should match its color:

1. **Aurora** (pink)
2. **Elixir** (medium light green, not too pale)
3. **Cloud** (light blue)
4. **Moonlight** (blue)
5. **White Sand** (ocean blue)
6. **Sea Sage** (green)

For each product, write a short, elegant description and plausible top, heart and base scent notes that suit the name and color. Mark these as placeholder text that the owner will replace.

## Sections

1. **Hero:** full-screen banner with the brand name, tagline and a "Shop Now" button.
2. **Product catalog:** a grid of the six perfumes. Each card shows a CSS-drawn 6 ml bottle in the product's color (no image files needed), the name, "6 ml · Oil-based perfume", the price and an "Add to Cart" button.
3. **Product detail modal:** a larger bottle illustration, description and scent notes.
4. **Shopping cart:** a slide-out drawer where users can add, remove and change quantities, with a live subtotal. Save the cart in localStorage.
5. **Checkout:** a form for name, phone number, delivery address and an order note, with an order summary. Payment method is **bKash**. Show the brand's bKash number (**[BKASH NUMBER]**) with clear instructions to send the total amount, and add fields for the sender's bKash number and Transaction ID (TrxID). After submission, show a confirmation message.
6. **About / brand story:** a short, elegant paragraph about Rosa Fragrance.
7. **Footer:** brand info, social links (including Facebook) and copyright.

## Technical Requirements

- Fully responsive for mobile, tablet and desktop.
- Sticky navigation bar with a cart icon showing the item count.
- Clean, well-commented code.
